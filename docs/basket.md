## Termes NBA essentiels

| Terme                                | Sens simple                                                                                                                   |
| ------------------------------------ | ----------------------------------------------------------------------------------------------------------------------------- |
| **Playoffs**                         | Phase finale de la saison NBA. Les meilleures équipes s’affrontent en séries éliminatoires.                                   |
| **Finales / Finals**                 | Dernière série des playoffs, pour le titre NBA.                                                                               |
| **Finales de conférence**            | Demi-finales NBA : une finale à l’Est, une finale à l’Ouest. Les gagnants vont en Finales NBA.                                |
| **Avantage du terrain**              | Une équipe joue plus de matchs à domicile dans une série. Par exemple 4 matchs chez elle contre 3 chez l’adversaire.          |
| **Seed / classement**                | Position d’une équipe avant les playoffs. Une équipe classée 1re est mieux “seedée” qu’une équipe classée 5e.                 |
| **Première option**                  | Joueur principal en attaque. C’est souvent celui qui prend les tirs importants et porte le scoring.                           |
| **Scoring**                          | Capacité à marquer des points.                                                                                                |
| **Shooteur**                         | Joueur bon au tir, surtout à longue distance.                                                                                 |
| **Spacing**                          | Espacement du terrain. Si une équipe a de bons shooteurs, la défense doit s’écarter, ce qui libère de l’espace pour attaquer. |
| **Meneur**                           | Le poste de “point guard”. Il organise le jeu, remonte la balle et crée des occasions.                                        |
| **Créateur**                         | Joueur capable de créer un tir ou une passe décisive, même quand l’action est difficile.                                      |
| **Volume de tirs**                   | Nombre de tirs tentés. Un joueur peut être très efficace, mais avec peu de tirs.                                              |
| **Efficacité**                       | Capacité à marquer beaucoup avec peu de tirs ou de possessions.                                                               |
| **Tir à trois points / 3 points**    | Tir derrière la ligne à trois points. Il vaut 3 points au lieu de 2.                                                          |
| **3PA**                              | Three Point Attempts : tentatives à trois points.                                                                             |
| **3P%**                              | Pourcentage de réussite à trois points. Exemple : 44,6 % veut dire que le joueur marque 44,6 % de ses tirs à trois points.    |
| **Rebond / REB**                     | Quand un joueur récupère le ballon après un tir raté.                                                                         |
| **GP**                               | Games Played : nombre de matchs joués.                                                                                        |
| **True Shooting / TS%**              | Stat avancée qui mesure l’efficacité au tir en tenant compte des tirs à 2 points, à 3 points et des lancers francs.           |
| **Relative True Shooting**           | True Shooting comparé à la moyenne de l’époque. Utile pour comparer des joueurs de différentes périodes.                      |
| **Highlights**                       | Actions spectaculaires : dunks, gros tirs, contres, passes impressionnantes.                                                  |
| **Gros marché / petit marché**       | Grande ou petite ville/franchise médiatique. Lakers = gros marché ; Thunder ou Pacers = plus petit marché.                    |
| **Public occasionnel / casual fans** | Fans qui suivent surtout les stars, les highlights ou les grandes affiches, pas forcément toute la saison.                    |

## Les plus importants pour comprendre tes questions

**Spacing** : très important. Quand tes cas disent qu’Orlando manque de spacing, ça veut dire que l’équipe n’a pas assez de shooteurs fiables. Du coup, les défenses peuvent se regrouper près du panier et rendre l’attaque plus difficile.

**Première option** : quand ton cas parle de Reggie Miller comme “première option”, ça veut dire qu’il était le joueur offensif principal de son équipe en playoffs.

**Volume vs efficacité** : un joueur peut être très efficace mais tirer peu. Exemple : s’il marque 20 points avec peu de tirs, il est efficace. Mais s’il ne prend pas beaucoup de tirs, son “volume” est limité.

**3PA / 3P%** : pour juger un shooteur, il faut regarder les deux. Un joueur à 50 % à trois points avec seulement 10 tirs, c’est moins significatif qu’un joueur à 44 % avec 500 tentatives.

**REB** : total de rebonds. Dans tes cas Excel, on cherche par exemple le joueur avec le plus grand total de rebonds.

**Cinq derniers matchs** : c’est une notion de période récente. Ton cas Q10 est justement un cas limite : si l’Excel ne contient que des stats de saison, on ne peut pas répondre correctement à une question sur les cinq derniers matchs.

En gros, pour lire tes évaluations : les questions qualitatives parlent surtout de perception des équipes/joueurs en playoffs ; les questions quantitatives parlent surtout de stats comme `3PA`, `3P%`, `REB` et `GP`.
